# Markdown Tool 升级设计（已确认）

日期：2026-11-13。基线：Side Comments 增强版 1.1.1。

用户于 2026-11-13 确认制作，并纳入五项补充功能。实现采用轻量原生 DOM／SVG 画布，复用 MIT Markdown 树解析与保真合并模块，不引入另一个完整插件依赖。

## 已确认目标

- 显示名称改为 Markdown Tool。保留插件 ID `side-comments-origin`、原批注格式和已有配置路径，继续通过原仓库和 BRAT 升级。仓库 URL 暂不变更，以免现有 BRAT 跟踪失效。
- 选中文字后右键可打开紧凑工具栏，提供文字标红、背景高亮、加粗、下划线、删除线、批注、清除标记；保留现有选区浮动入口。文字红色与红色背景高亮分开表达。移动端提供不依赖右键的入口。
- 任意新建或已有 Markdown 文件，右上角一键在 Markdown 与思维导图之间切换；空白文件也可直接开始添加节点。无需手写导图代码块，不额外建立 `.wmind` 或镜像笔记。
- 两种视图编辑同一份 Markdown：节点文字、增删、层级调整均双向同步；保留未修改区域的原文、正文、代码块、表格和 frontmatter。
- 用户已确认：关联线可编辑关系文字；多个节点可添加总括，总括下面还能继续添加可编辑子节点。

## 路线比较

1. 推荐：在本插件内按需加载导图能力，评估复用本地 personal-mindmap 中的解析、同步与图形能力。用户只需安装一个插件，但要验证模块边界、包体积、移动端和已有批注的兼容。
2. 依赖单独的 personal-mindmap 插件：本插件更轻，但需要用户额外安装配置，两个插件的版本也会互相约束。
3. 导出独立导图文件：实现更直接，但会产生重复文件，偏离用户要求，不采用。

## 数据与编辑规则

- Markdown 是正文唯一来源。连线标签、节点稳定标识、总括范围和总括子树等扩展信息保存在同一 Markdown 文件的版本化隐藏注释中。切换视图不产生重复文件。
- 普通节点文本与层级使用可读 Markdown；图形特有结构需要保存映射，并在大纲界面提供可编辑入口。总括子树的具体可读表示在实现前固定，并通过双向往返样例验证，避免重复内容。
- 图形修改只更新受影响的内容；不能安全定位时提示冲突，不覆盖不相关正文。外部编辑后重新匹配节点，无法匹配的连线或总括保留恢复信息。
- 复用批注锚点策略时，需验证节点移动、同名节点和跨段编辑；无法重定位时明确显示定位异常，不能静默绑定到错误文字。
- 画布只在打开导图时加载，关闭后释放事件、监听器和画布资源。减少重复数据不等于零内存开销，不承诺未经实测的性能收益。

## 建议补充的必要交互

- 大纲与导图的撤销、重做，以及切换视图后可恢复的编辑历史策略。
- Tab 添加子节点、Enter 添加同级、双击编辑；触屏提供对应按钮。
- 折叠、展开、搜索定位、适应画布，方便处理长笔记。
- 明确保存中、已保存、失败与外部修改冲突状态；失败时保留待恢复编辑。
- 导图支持查看原批注和文字标记，避免切换后失去重点。

首版不额外加入 AI、在线协作或独立格式导入等扩展范围。
