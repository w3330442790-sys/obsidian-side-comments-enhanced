# Taube Markdown Tool

基于 [Side-Comments-origin](https://github.com/jepicaju862-lab/Side-Comments-origin) 的 Obsidian 批注插件增强版。保留原有功能与批注数据格式，增加手机、平板使用所需的保存与复习操作。

- 当前版本：**1.6.0**（Obsidian 1.8.7 或更新版本）
- 支持：Windows、macOS、Linux，以及 Obsidian 手机／平板端
- 插件 ID：`taube-markdown-tool`，独立于原社区版更新
- [下载最新版本](https://github.com/w3330442790-sys/taube-markdown-tool/releases/latest)

## 手机和平板安装：BRAT

1. 在 Obsidian 的“设置 → 第三方插件”中安装并启用 **BRAT**。
2. 打开 BRAT 设置，选择 **Add beta plugin**。
3. 填入仓库地址：

   ```text
   w3330442790-sys/taube-markdown-tool
   ```

4. 选择最新版本（Latest），添加并启用 **Taube Markdown Tool**。
5. 后续通过 BRAT 检查此仓库的更新。

这是通过 GitHub／BRAT 安装的版本，尚未作为独立插件提交到 Obsidian 官方插件目录。

如果已经安装原版：先备份批注数据与原插件目录，再停用原版并通过 BRAT 添加本仓库。**不要先卸载原插件或删除数据目录。**如果 BRAT 正在跟踪上游原仓库，先移除原仓库的更新跟踪，再添加本仓库，避免上游更新覆盖增强版。1.4.0 起插件 ID 与仓库统一为 `taube-markdown-tool`，原版与旧的 `personal-markdown-tool` 目录都保持停用、不删除。首次启用新 ID 时，仅在新目录缺少对应文件时按「personal-markdown-tool → side-comments-origin」的顺序复制 data.json 与 enhancements.json，保留自定义批注路径、筛选和未知字段；不删除旧目录、不改笔记。之后设置保存在新插件目录。启用新插件后请在“设置 → 第三方插件”里停用旧的 `personal-markdown-tool` 与 `side-comments-origin`，避免同时写入批注数据。

## 已有批注与跨设备同步

插件直接兼容原始批注 JSON，无需从 SideNote 汇总笔记重新导入：

- `side-note-data/`：默认原始批注目录。
- `.obsidian/plugins/side-comments-origin/data.json`：原设置与部分旧版数据。
- `side-note-attachments/`：默认批注图片目录。

这些路径可在原插件设置中自定义。**在另一台设备安装插件，不等于同步笔记或批注。**请通过自己的同步方式同步原笔记、实际批注数据目录和附件。跨设备同时编辑同一份批注数据时，需要由同步工具处理冲突。

## 新增功能

1.3.0 新增拖动调整层级与 Markdown 工具栏：

- **拖动调整层级**：正文左侧为每个段落、列表项、标题显示拖动手柄。鼠标拖动或用手指拖动即可移动整块内容；拖到标题／列表项中部成为它的子项（自动加一级标题或缩进），拖到上下边缘调整顺序。Markdown 文字同步改写，原有批注跟着原文一起移动，不丢标记。无法拖动文件末尾的 `<!-- markdown-tool:v1 … -->` 隐藏数据行。
- **Markdown 工具栏**：编辑器顶部固定一排按钮：H1–H3、加粗、斜体、删除线、高亮、行内代码、引用、无序列表、有序列表、任务清单、代码块、链接、表格、分割线、清除标记。选中文字或放置光标后点击即可；再次点击同一按钮取消。每个按钮都注册为 Obsidian 命令，可自行绑定快捷键。
- **键盘与触屏替代**：命令“上移／下移当前块”“降低／提升当前块层级”与拖动等效，方便键盘操作或手柄不好按的场景。
- 设置里可分别关闭“显示 Markdown 工具栏”和“启用拖动调整层级”。

1.2.0 将选区标记、原批注、大纲与思维导图集中在同一插件：

- **文字标红**：选中文字后右键选择“打开文字工具栏”，或使用浮动工具栏。文字颜色与背景高亮独立，清除所选标记会保留批注正文。
- **一键导图**：新建或打开 `.md`，点击右上角脑图按钮；不需要代码块或 `.wmind`。导图内可切换可编辑“大纲”，或“返回 Markdown”直接编辑原文。
- **关系与总括**：选起点后点“添加关联线”，再选终点并编辑文字。Ctrl／Cmd／Shift 或“多选”选择连续同级节点后添加总括；选中总括后“添加子节点”可继续分点。
- **编辑与复习**：撤销／重做、折叠、搜索定位、适应画布、原批注查看，以及明确保存状态。Tab 添加子节点、Enter 添加同级，F2 编辑，Ctrl／Cmd+Z 撤销。
- **冲突恢复**：外部内容变化时不覆盖磁盘；可预览或复制本地内容后载入磁盘版本。先前冲突内容保留于本机恢复存储，可再次预览、恢复或清除；不额外创建笔记文件。

Markdown 是正文来源；关联线、总括子树与节点标识保存在文件末尾的 `<!-- markdown-tool:v1 … -->` 注释中，请保留它。总括子树可在插件“大纲”中直接编辑。普通 Markdown 中改名和层级变化会重新匹配；无法确定的重复节点不会静默重绑，扩展数据会保留并提示。总括范围内节点调整位置／层级前需先移除总括。

段落、代码和表格作为节点备注保留，可在原 Markdown 中编辑。画布按需创建，但运行仍会占用内存。撤销历史只在当前插件会话内保留最近访问的 12 份文档，重启后不保留；拖动、工具栏和导图的撤销同样只使用本次会话的内存历史，不会写进笔记、`data.json` 或本机恢复存储。冲突恢复内容按设备保存，不跨设备同步。

1.5.0 新增定位异常批量修复：

- 侧栏“定位异常”旁新增“批量修复”，设置页与命令面板也有入口；先校验批注记录的原文位置，再按全篇唯一文本、标题段内唯一文本依次自动恢复。
- 无法确定唯一位置的批注继续保留为定位异常，绝不静默绑到错误文字上；修复成功后会同步刷新上下文、标题路径与出现序号，降低以后再次异常的概率。
- 重复文本现在优先在所属标题段内判定，段内唯一即可恢复，减少标题结构内重复词造成的误判。

1.6.0 侧栏体验调整：

- 在正文点击带批注的高亮时，对应批注卡片会置顶显示在侧栏最上方并滚动到顶部，不再停留在列表最下。
- 顶部工具区压缩为两行：搜索一行，筛选、定位异常、显示全部、常用筛选一行；保存筛选、管理筛选、恢复草稿收进“更多”菜单。
- 按钮与下拉框高度、内边距、导航行同步收紧，减少占用批注阅读空间。

以下原有增强功能继续保留：

| 功能 | 行为 |
| --- | --- |
| 样式＋颜色筛选 | 组合筛选高光、下划线等样式及指定颜色，只影响侧栏列表 |
| 常用筛选 | 命名保存、快捷调用、删除，并恢复上次筛选条件 |
| 上一条／下一条 | 按当前筛选和排序浏览，显示当前条数及总数 |
| 批注重新绑定 | 列出定位异常的批注，选中新原文并确认绑定，保留正文、时间、颜色和样式 |
| 保存与状态 | 明确的“保存”键，显示未保存、保存中、已保存及失败状态 |
| 本机草稿 | 自动暂存输入、误关恢复、恢复列表、失败重试；草稿不跨设备同步 |
| 一键收起选项 | 搜索、工具栏与筛选统一收起，保留导航和计数，记住本机状态 |
| 手机／平板布局 | 放大触控按钮，适配窄侧栏、横屏和软键盘可见视口，保留保存栏 |

原有 Markdown 批注、图片、正文标记、阅读模式交互、搜索、排序、导出等功能继续保留。原版默认黄色 `#ffc800` 与预设黄色 `#f59e0b` 按实际色值分别筛选。

详见 [增强版使用说明](增强版使用说明.md) 和 [更新记录](CHANGELOG-增强版.md)。已完成隔离交互测试和 Windows Obsidian 加载检查；真实 iPad／安卓设备仍需使用者验证实际体验。

## 手动安装与回退

从 [Release](https://github.com/w3330442790-sys/taube-markdown-tool/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`，放入笔记库的 `.obsidian/plugins/taube-markdown-tool/` 后重载插件。保留旧 `side-comments-origin` 数据目录用于首次设置迁移，旧版保持停用。

不要替换自己的 `data.json`、`enhancements.json` 或批注数据目录。回退时只恢复旧插件的程序文件，避免用旧备份覆盖升级后的新批注。
